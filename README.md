# Retail-Revenue-Analysis
Retail Revenue Analysis is a data analytics project focused on analyzing retail sales, customer purchasing behavior, product performance, and revenue trends. The project transforms raw retail data into meaningful business insights using Excel, SQL, Python (Pandas), and Power BI.
# Objectives
Analyze overall retail revenue and sales performance.
Identify top-performing products and stores.
Understand customer purchasing patterns.
Segment customers based on Recency, Frequency, and Monetary (RFM) analysis.
Analyze sales trends and revenue distribution.
Provide interactive dashboards for business decision-making.
# Tools & Technologies
Excel – Data cleaning, formulas, VLOOKUP/XLOOKUP, Pivot Tables and analysis.
SQL – Data querying, joins, aggregations, filtering and business analysis.
Python (Pandas) – Data exploration, statistical analysis and customer segmentation.
Power BI – Interactive dashboards, KPIs, charts, slicers and data visualization.
# Key Analysis
Total Revenue and Total Orders
Average Order Value
Revenue by Store and Customer
Top-selling Products
Sales Trends over Time
Customer Purchase Behavior
Customer Segmentation: Loyal, New, At-Risk
